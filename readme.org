* Emacs Configuration / Emacs設定

** Installation / インストール

#+begin_src bash
  # Remove existing config (optional)
  rm -rf ~/.emacs.d

  # Clone this repository
  git clone https://github.com/xinii/config-emacs.git ~/.config/emacs
  # or
  git clone https://github.com/xinii/config-emacs.git ~/.emacs.d
#+end_src

- EN: Clone the repo and start Emacs.
- JA: リポジトリをクローンしてEmacsを起動するだけです。

** Architecture / 構成

Modern, minimal, and close to upstream Emacs.

モダンで最小構成、かつEmacs標準に近い設計。

- Completion UI: ~corfu~
- Matching style: ~orderless~
- Minibuffer UI: ~vertico~
- Search & commands: ~consult~
- Annotations: ~marginalia~
- Completion sources: ~cape~
- LSP client: ~eglot~
- Projects: ~projectile~
- AI: ~gptel~

** Philosophy / 設計思想

Less, but better.

少なく、しかし良く。

- Drop large frameworks (helm, auto-complete)
- Prefer built-in + small packages
- Use LSP as the standard interface

#+begin_quote
Small, composable pieces over monolithic systems.
#+end_quote

** Notes / 注意

Terminal users (~emacs -nw~):

#+begin_src elisp
(use-package corfu-terminal
  :after corfu
  :config
  (corfu-terminal-mode 1))
#+end_src

- EN: Required for popup completion in terminal
- JA: ターミナルで補完UIを表示するために必要

LSP:

- EN: Requires external servers (e.g. pyright)
- JA: 外部LSPサーバー（例: pyright）が必要
